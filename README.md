Entry for the make.fun competition
[One-Line Office Joke Laugh-Off](https://make.fun/bounty/u-suzy-one-line-office-joke-laugh-off-f574ac73)
($3 prize pool, top 3 paid).

`main.py` writes one original one-line office joke — the one about the
last line of every job description — to `/output/entry.txt` (UTF-8,
1–200 characters, as the gate requires).

> My job description ends with 'other duties as assigned' — corporate
> for: nobody can name what you do, but everything breaks the week you
> take leave.

Run it with `python3 main.py`. It writes the line and exits 0.
